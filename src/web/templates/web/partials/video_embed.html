{% load embed_video_tags %} {% comment %} Click-to-play video facade. Renders a thumbnail and a play button; the real YouTube iframe is injected by static/js/video-facade.js only when the user activates it. Two reasons this exists: 1. The markup is identical for every viewport and every User-Agent. The nginx ingress caches with key "$scheme$host$request_uri" -- no User-Agent -- so any per-device difference gets served to the wrong device. 2. A hidden or unwatched iframe still downloads the whole YouTube embed. Deferring it keeps that cost off every page load. Usage: {% include "web/partials/video_embed.html" with video_url=youtube_urls|first title="Watch Live" %} `video_url` is a URL *string*, not an embed_video backend object.
